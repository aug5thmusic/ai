# Music
The [music](https://github.com/aug5thmusic/ai/tree/main/music) folder contains the MIDIs, PDFs, and LilyPond files of LLM-generated music I have posted to my [𝕏/Twitter](https://x.com/aug5thmusic) account. Currently, the files are organized by track title ("Neon Tide" by Claude Opus 5.5 is `neon-tide`). Prompt and model information for each track is found in [`music\prompts-and-models.txt`](https://github.com/aug5thmusic/ai/blob/main/music/prompts-and-models.txt).

# Engraving
The engraving folder contains projects relating to AI-assisted [music engraving](https://en.wikipedia.org/wiki/Music_engraving).
